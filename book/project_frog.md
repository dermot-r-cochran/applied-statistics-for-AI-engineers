# Project Frog: the fictional teaching environment

Project Frog is the continuous case study for this book.

It is a fictional AI-assisted document analysis and decision-support platform. It processes synthetic documents and produces synthetic classifications, extracted fields, evidence summaries, explanations, recommendations, and decisions.

## Why use a fictional system?

The point of the book is to teach reusable reasoning, not to describe a real stack. A fictional environment makes it easier to isolate the statistical lesson without importing proprietary terminology, implementation detail, or domain-specific assumptions from an actual organization.

## What Project Frog measures

Depending on the chapter, Project Frog may report synthetic metrics such as:

- accuracy
- precision
- recall
- F1 and F-beta
- agreement rate
- coverage
- evidence quality
- text similarity
- latency
- processing cost
- confidence-like component scores

## Ground rules

All Project Frog data in this repository must be:

- synthetic
- programmatically generated or clearly fictional
- free of personal, customer, confidential, or proprietary content
- used only to illustrate transferable evaluation problems

## Recurring lessons from Project Frog

Project Frog exists to help readers practice questions such as:

- Did the system get worse, or did the sample get smaller?
- Are two reported metrics comparable across versions?
- Does a statistically detectable difference matter operationally?
- What happens when observations are clustered rather than independent?
- Can a release target be considered achieved under uncertainty?

The Project Frog case studies are meant to be argued with, not merely read. Treat them as decision reviews.
