Lesson A: Sampling distributions and standard error

1) Engineering question

You observed FRG row-level exact-match accuracy drop from 0.84 to 0.81. Is this likely a true regression or sampling variation?

2) Core statistical principle

A metric computed on a finite sample is a random variable. Repeated re-sampling gives a sampling distribution. Its spread is summarized by the standard error (SE).

3) Essential mathematics

For binary outcomes Xi in {0,1}, p-hat = (1/n) * sum(Xi), with Var(p-hat) ≈ p(1-p)/n. Replacing p with p-hat gives:

SE(\hat{p}) ≈ sqrt( p̂(1-p̂)/n )

A rough 95% interval under normal approximation is p̂ ± 1.96×SE.

4) Assumptions

  • Examples are approximately independent.
  • Ground truth and metric definition are unchanged between runs.
  • Comparison is like-for-like (same thresholding and scenario definition).
  • Test set represents the intended population.

5) Worked AI-evaluation example (synthetic)

Synthetic data: Run A has 420/500 exact matches (0.84). Run B has 405/500 (0.81).

For Run A, SE ≈ sqrt(0.84×0.16/500)=0.0164. For Run B, SE ≈ sqrt(0.81×0.19/500)=0.0175.

The standard error of the difference is approximately sqrt(SE1²+SE2²)=0.024. The observed difference is 0.03, around 1.25 SE of the difference, so evidence is weak for a true shift without stronger design (for example paired comparison on same examples).

6) Common interpretation error

“The test set is small, so we should adjust accuracy upward.”

Correction: smaller n increases uncertainty; it does not justify changing the point estimate.

7) FRG application

  • Report row-level point estimate and uncertainty together.
  • State unit of analysis (cell/row/document/project) before interpreting variance.
  • Check for clustering by document/project before treating n as effective sample size.

9) One small applied exercise

Given a synthetic FRG verdict-pass rate of 92/120, compute a Wilson 95% interval and explain whether a drop to 88/120 in the next run is distinguishable without paired data.

Python reproducibility snippet

import math
p1, n1 = 420/500, 500
p2, n2 = 405/500, 500
se1 = math.sqrt(p1*(1-p1)/n1)
se2 = math.sqrt(p2*(1-p2)/n2)
print("Run A:", p1, se1)
print("Run B:", p2, se2)
print("Observed difference:", p1-p2)

The output quantifies both estimates and uncertainty, making clear that the observed gap must be interpreted with design assumptions, not just raw point values.
