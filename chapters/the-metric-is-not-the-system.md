# The Metric Is Not the System

A useful metric measures one slice of behavior. It does not prove that the whole AI pipeline is ready for deployment.

## Why this matters in Project Frog

Project Frog routes fictional field reports into four classes: `Clear`, `Review`, `Insufficient`, and `Escalate`. A strong aggregate accuracy number can still hide subgroup failures, escalation misses, or brittle confidence semantics.

## Read this chapter before or after the tutorial

Use the [interactive Project Frog tutorial](../tutorials/project-frog-progressive-evaluation.md) when you want a hands-on path from intuition to interpretation.

## Key reminders

- A metric is a lens, not a verdict.
- The evaluation sample is part of the measurement.
- Operational decisions need uncertainty, not just point estimates.
