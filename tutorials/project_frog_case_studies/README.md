# Project Frog case studies

Each case study is a fictional evaluation review designed to answer the same core question in a different way:

> When should an engineer trust an observed AI metric strongly enough to act on it?

These exercises are intentionally short. The point is to practice identifying the decision, the population, the uncertainty, the assumptions, and the operational consequence of getting the conclusion wrong.

2. Frog Leap
3. Different Pond
4. The Tadpole Problem
5. Release Readiness
