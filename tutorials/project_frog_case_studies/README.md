# Project Frog case studies

These case studies are short decision exercises built around the same fictional system used across the book.

## Cases

1. **The Shrinking Pond** — a lower score on a much smaller sample
2. **Frog Leap** — a modest model improvement that may or may not matter
3. **Different Pond** — changed dataset composition and comparability risk
4. **The Tadpole Problem** — clustered observations and misleading sample size
5. **Release Readiness** — threshold decisions under interval uncertainty

Use them after the core chapters or as a fast route into the book's main question: when is a metric trustworthy enough to support action?
