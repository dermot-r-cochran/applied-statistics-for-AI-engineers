# Tutorials

Hands-on tutorials connect the statistical ideas from the book to executable Project Frog examples.

Use them when you want to move from conceptual understanding to calculation, visualization, and interpretation.

## Included tutorial areas

- `confidence_intervals/`: interval estimation for accuracy and related metrics
- `bootstrap/`: resampling intuition and uncertainty estimation
- `classification_metrics/`: interpreting metric trade-offs and prevalence effects
- `test_set_design/`: building representative evaluations
- `power_analysis/`: planning studies before running them
- `project_frog_case_studies/`: scenario-based decision exercises
