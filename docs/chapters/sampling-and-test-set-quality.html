Sampling and test-set quality

A test set is a measurement instrument. If it is biased, stale, or too narrow, the metric it produces is misleading.

Four checks for a teaching-grade evaluation set

  1. Coverage: include the deployment habitats, seasons, and edge cases you care about.
  2. Label quality: document how synthetic labels were assigned and where they are uncertain.
  3. Comparability: keep inclusion criteria fixed when comparing model runs.
  4. Refresh policy: review whether the sample still reflects current production conditions.

Interval width is part of test-set quality

A small test set should widen the uncertainty band rather than encouraging the same interpretation of the point estimate. Treating 89% on 100 cases as equally stable to 89% on 1,000 cases hides real measurement uncertainty.

Sample size is not the only design choice that matters. If evaluation rows come from the same pond visit, camera, or labeling batch, row-count-based intervals may still be too narrow because the observations are partly dependent.

How design changes the uncertainty story

Synthetic scenario Observed accuracy Interval treatment
1,000 independent fictional sightings with 89% observed accuracy 89% Use a relatively narrower interval because repeated samples would vary less.
100 independent fictional sightings with 89% observed accuracy 89% Use a wider interval because the same point estimate is less stable on fewer cases.
100 rows collected from a few repeated pond visits 89% Consider an even wider interval or a reduced effective sample size because rows are not fully independent.

Decision habit

Never report a single top-line metric without stating what population it estimates, which assumptions justify the interval, and what cases were excluded from measurement.
