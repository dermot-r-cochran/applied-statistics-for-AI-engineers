Comparability and decisions

Metrics matter only when they support a controlled comparison and a clear operational choice.

Rules for a fair model comparison

  • Use the same evaluation slice definitions.
  • Keep label policy fixed.
  • Apply the same routing threshold or compare across a threshold sweep.
  • Record the observed metric with an interval and assumptions so small differences do not masquerade as real improvements.

Reporting habit

Evaluation reporting should present the observed metric together with an interval estimate and the assumptions behind it. If the test set is smaller, the interval should widen; if rows are clustered or otherwise dependent, the uncertainty treatment may need to widen again.

Ship

Use when the new model improves the chosen objective, preserves calibration, and does not create unacceptable slice regressions.

Hold

Use when the sample is too small, too stale, or too confounded to justify a change.

Collect evidence

Use when the largest uncertainty is about labeling, missing strata, or whether deployment conditions have shifted.

Project Frog operating note

The safest decision is often to delay automation expansion until the evidence is comparable and calibrated. Trustworthy evaluation favors reversible moves over metric theater.
