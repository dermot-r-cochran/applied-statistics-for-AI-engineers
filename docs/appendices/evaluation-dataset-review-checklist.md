# Evaluation dataset review checklist

- [ ] Target population is named explicitly.
- [ ] Sampling frame is documented.
- [ ] Inclusion and exclusion rules are reproducible.
- [ ] Known clusters or repeated measures are identified.
- [ ] Coverage across important subgroups is summarized.
- [ ] Missing or thinly covered conditions are disclosed.
- [ ] Labeling guidance and adjudication are versioned.
- [ ] Dataset purpose is matched to the claimed use.
- [ ] Holdout protections and leakage risks are reviewed.
- [ ] Update history and governance owner are recorded.
