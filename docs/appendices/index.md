# Appendices and Reference Material

This section gathers reusable artifacts, definitions, and decision aids that support the main book chapters. Use it as a reference shelf for glossary terms, metric and interval selection, evaluation governance, and experiment design templates.

## What lives here

- Glossary entries for recurring statistical and evaluation terms
- Quick guides for metric and interval selection
- Review checklists for AI evaluation, comparability, and dataset quality
- Reusable templates for manifests, protocols, metric cards, and planning worksheets
- Confidence-related reference material for score semantics and composition reviews

## Suggested use

Read these pages alongside the main chapters rather than as a separate narrative. The chapters introduce the concepts; the appendix pages help teams apply them consistently in real evaluation workflows.
