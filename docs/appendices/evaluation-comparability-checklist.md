# Evaluation comparability checklist

Declare one of the following outcomes for every comparison:

- **Directly comparable**
- **Comparable with limitations**
- **Not directly comparable**

## Required checks

- [ ] Same examples or a justified sampling design for independent comparison
- [ ] Same ground truth and adjudication policy
- [ ] Same scoring code and metric definitions
- [ ] Same thresholds or operating points
- [ ] Same preprocessing and feature preparation
- [ ] Same operating conditions and routing rules
- [ ] Same inferential unit or a documented translation between units
- [ ] Same reporting period or documented temporal shift

## If limitations remain

Record the limitation, its likely direction of effect, and whether the headline comparison should be softened or withheld.
