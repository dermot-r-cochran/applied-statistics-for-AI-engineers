## Key questions

- What action will change if the result crosses the threshold?
- What is the minimum effect that would matter operationally?
- How should uncertainty be reported when evidence is not yet decisive?


## Engineering interpretation

Write the decision rule before collecting data. That keeps the experiment focused on meaningful effect sizes, relevant subgroups, and defensible evidence thresholds.
