# Part V: Experimental Design

Experiments become decision-worthy when comparisons are fair, effects are meaningful, and uncertainty estimates match the sampling design.

## What this part does

This part establishes the main questions, failure modes, and decision responsibilities for the chapters that follow.

## Chapters in this part

- [16. Start with the Decision](../part-v-experimental-design/16-start-with-the-decision.md) — Experimental design should start from the decision to be supported, because the right metric, effect size, and evidence threshold all depend on what action is at stake.
- [17. Fair Model Comparisons](../part-v-experimental-design/17-fair-model-comparisons.md) — A model comparison is only as fair as its shared conditions: examples, labels, thresholds, preprocessing, scoring, and operating environment.
- [18. Effect Size Before Significance](../part-v-experimental-design/18-effect-size-before-significance.md) — A statistically detectable change is not automatically meaningful, so experiments should define practical effect sizes before asking whether the result is significant.
- [19. Power and Sample-Size Planning](../part-v-experimental-design/19-power-and-sample-size-planning.md) — Sample-size planning is about giving the experiment a realistic chance to detect meaningful effects under the actual sampling structure.
- [20. Bootstrap, Permutation, and Simulation](../part-v-experimental-design/20-bootstrap-permutation-and-simulation.md) — Resampling methods are useful because they can align uncertainty estimation with complex metrics and sampling designs, but each method has assumptions that can be violated easily.

## Throughline
