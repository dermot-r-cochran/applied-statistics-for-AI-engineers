# Project Frog

Project Frog is the continuous fictional case study used throughout this repository.

## What Project Frog is

Project Frog is a fictional AI-assisted document analysis and decision-support platform. It processes **synthetic** documents and may produce:

- classifications
- extracted fields
- evidence snippets
- explanations
- recommendations
- decisions

## What Project Frog measures

Project Frog may report synthetic metrics such as:

- accuracy
- precision
- recall
- F1 and F-beta
- agreement rate
- coverage
- evidence quality
- text similarity
- latency
- processing cost
- confidence-like component scores

## Why use a fictional system?

A fictional teaching environment makes it easier to focus on recurring evaluation failures without importing any real organization, product, customer, architecture, dataset, or workflow. The lessons are meant to transfer; the implementation details are intentionally invented.

## Synthetic data standard

All Project Frog datasets in this repository are programmatically generated and explicitly synthetic. They are meant for examples, tests, notebooks, and demonstrations only.

## Continuous decision thread

Project Frog is the place where the book keeps returning to the same question:

> When should an engineer trust an observed AI metric?

The answer changes with the metric definition, the sample design, the dependence structure, the uncertainty estimate, and the decision that depends on it.
