# Part VI: From Evidence to Decisions

The final step is translating uncertain evidence into decisions, monitoring, and communication practices that remain honest about what is still unknown.

## What this part does

This part establishes the main questions, failure modes, and decision responsibilities for the chapters that follow.

## Chapters in this part

- [21. Release Readiness Under Uncertainty](../part-vi-from-evidence-to-decisions/21-release-readiness-under-uncertainty.md) — Release readiness is a decision under uncertainty, so point estimates must be combined with thresholds, risk appetite, and the consequences of being wrong.
- [22. Monitoring Is an Ongoing Experiment](../part-vi-from-evidence-to-decisions/22-monitoring-is-an-ongoing-experiment.md) — Post-release monitoring is not a static dashboard; it is a continuing experiment that asks whether the deployed system is still operating in the population and conditions the evaluation assumed.
- [23. Communicating What the Evidence Does Not Prove](../part-vi-from-evidence-to-decisions/23-communicating-what-the-evidence-does-not-prove.md) — Trustworthy reporting includes uncertainty, assumptions, exclusions, and unsupported claims so stakeholders can act without overreading the evidence.
- [24. Building an AI Evaluation Strategy](../part-vi-from-evidence-to-decisions/24-building-an-ai-evaluation-strategy.md) — A durable evaluation strategy connects metrics, datasets, confidence, experimentation, governance, and decision-making into one repeatable operating system.

## Throughline

Project Frog reappears across these chapters so ideas connect through one synthetic workflow rather than isolated examples.
