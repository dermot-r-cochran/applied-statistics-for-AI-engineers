## Engineering interpretation

Treat every metric as a lossy interface between the real system and a decision. Engineers should document scope, blind spots, and escalation rules alongside the metric definition.

## Project Frog integration

Project Frog uses document triage labels (`Clear`, `Review`, `Insufficient`, `Escalate`) to support case routing, but chapter 1 makes clear that routing quality, latency, and review burden are separate system outcomes.
