# Evaluation Dataset Review Checklist

- Target population is defined
- Sampling frame is documented
- Unit of observation is documented
- Unit of inference is documented
- Clusters and repeated observations are documented
- Difficulty or subgroup composition is documented
- Coverage gaps are known
- Missing-data policy is defined
- Ground-truth process is versioned
- Scoring code is versioned
- Prior benchmark comparability implications are reviewed
- Retirement or refresh conditions are defined
