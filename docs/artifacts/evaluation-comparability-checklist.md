# Evaluation Comparability Checklist

Mark each item as **same**, **different**, or **undocumented**.

- Examples used
- Ground truth used
- Scoring code used
- Metric definitions used
- Thresholds used
- Preprocessing used
- Operating conditions used

## Result classification
- Directly comparable
- Comparable with limitations
- Not directly comparable

## Required explanation
- What changed?
- Why did it change?
- How could the change affect the metric?
- What claims remain safe to make?
