# Confidence-interval notebook

The repository's first hands-on notebook is:

`tutorials/confidence_intervals/confidence_intervals_for_accuracy.ipynb`

## What it covers

- accuracy as a binomial proportion
- standard error
- Wilson intervals
- Clopper-Pearson intervals
- bootstrap intervals
- visualization of uncertainty
- sample-size effects

## Core lesson

A smaller sample increases uncertainty around the estimate, but it does not automatically make the system's true accuracy lower.

## Run it locally

```bash
uv run jupyter lab tutorials/confidence_intervals/confidence_intervals_for_accuracy.ipynb
```
