# Tutorials and workshops

The tutorials keep the book operational. They provide notebook-first and scenario-first ways to practice the same evaluation questions raised in the chapters.

## What to run

- `tutorials/confidence_intervals/confidence_intervals_for_accuracy.ipynb`
- `examples/project_frog_metrics_demo.py`
- the Project Frog case studies in `tutorials/project_frog_case_studies/`

## Recommended sequence

1. Start with the rendered confidence-interval notebook in this site.
2. Read the case studies and write down your decision before checking the chapter material.
3. Use the `applied_stats_ai` helpers to reproduce the calculations in code.
