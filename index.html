Applied Statistics for AI Evaluation Engineers

This site is a practical coaching workspace for production AI evaluation, with FRG-aligned examples and exercises.

Learning objective

Distinguish real system changes from sampling variation, sampling bias, measurement error, test-set composition changes, class-distribution changes, drift, and misleading aggregation.

Core reasoning rules

  • Point estimate vs uncertainty
  • Small sample vs biased sample
  • Statistical vs practical significance
  • Row count vs effective sample size
  • Independent vs clustered observations
  • Model regression vs test-set composition change
  • Metric variance vs metric-definition change
  • Association vs causation
  • Exploratory analysis vs confirmatory evaluation
